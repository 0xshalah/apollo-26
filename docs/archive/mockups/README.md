# Archived mockups (superseded)

These static HTML files are early visual explorations made before PRD v2.1. They are kept only as design history.

They are **not** the application and contain claims and behaviour that were later rejected: VERB 97, V06/V16, 1200 baud, "0 dB", "100%", invented latency/SNR numbers, simulated FSK bits, a fake PBT runner, toggleable safety rules, and a fictional `acoustic_carrier_detected` hook.

The real ground station and mission console live in [`web-dashboard/`](../../../web-dashboard/). Claims allowed in the project are listed in [`.kiro/steering/product.md`](../../../.kiro/steering/product.md) and [`docs/evidence-matrix.md`](../../evidence-matrix.md).
