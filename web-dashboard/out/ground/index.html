Ground station

Builds a 34-byte acoustic frame v1 and transmits it at 300 baud (Bell-202, 1200/2200 Hz). The daemon decides whether a frame is accepted; this page only reports browser playback.

Signing keys (session only)

Keys stay in this tab's memory. They are never stored, sent over the network, or included in the page bundle. COMMAND uses the link key; AUTH uses the operator key.

Public demo keys come from the protocol contract. They are not secret: anyone can forge frames with them. Use them only with a daemon configured for the public demo.
