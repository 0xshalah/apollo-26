Apollo-26

An emergency command path without an IP interface: the ground station transmits authenticated 300-baud Bell-202 frames as sound, the local daemon validates them, and a Kiro Flight Watch session plans DSKY input through the MCP safety gate for an AGC-faithful subset emulator (P00 and simplified P40).

  • Ground stationCompose, sign, inspect, and transmit COMMAND and AUTH frames.
  • Mission consoleRead-only DSKY, spectrum, frame audit, and status from the local daemon.

The emulator does not run Luminary or Colossus flight software. Kiro uses a cloud LLM; only the daemon–MCP–AGC command path is local.
